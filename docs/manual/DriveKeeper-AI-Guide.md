# 드라이브 지킴이 (DriveKeeper) — AI 도우미용 안내서

> 이 문서는 ChatGPT·Claude 같은 AI가 읽고 사용자의 질문에 정확히 답하도록 쓴 참고서입니다.
> 사용자에게 답할 때는 **쉬운 한국어**로, 단계는 번호를 매겨 하나씩, 단추 이름은 [대괄호]로 알려 주세요.
> 사람이 보는 그림 안내: 홈페이지의 **따라 하기** https://janghwansangai.github.io/drive-keeper/start.html (한 화면에 한 단계, 인쇄용은 `드라이브 지킴이 사용설명서.pdf`).
> 사용자가 막히면 해당 장의 주소를 알려 주세요: `start.html#install`(설치) · `#key`(열쇠 만들기) · `#connect`(연결) · `#add`(계정 추가) · `#help`(막혔을 때).

- 프로그램: 드라이브 지킴이 (영문 DriveKeeper), Windows 10/11용
- 버전: 2.0.1 (최신 버전은 홈페이지에서 확인)
- 홈페이지: https://janghwansangai.github.io/drive-keeper/
- 최신 다운로드: https://github.com/janghwansangai/drive-keeper/releases/latest

## 1. 이 프로그램은 무엇인가요 (목적)

구글 드라이브를 PC에 연결(예: "Google Drive 데스크톱"으로 `G:` 드라이브를 만드는 것)하면, 그 PC를 쓰는 **누구나 비밀번호 없이** 드라이브의 모든 파일을 열고, 고치고, 지울 수 있습니다. 잠금 장치가 없습니다.

드라이브 지킴이는 이것을 보완합니다.

1. **비밀번호 잠금**: 켤 때, 자리를 비웠을 때, 절전에서 돌아왔을 때, 또는 단추로 바로 잠급니다.
2. **드라이브를 통째로 연결하지 않음**: 목록만 보여 주고, 두 번 누른 파일 **하나만** PC로 받아 엽니다.
3. **저장하면 자동으로 올라감**: Word·Excel·한글에서 Ctrl+S를 누르면 1~3초 뒤 구글 드라이브의 원본이 바뀝니다.
4. **지우기·공유 변경 차단**: 이 프로그램은 드라이브의 파일을 지우거나 휴지통에 넣거나 공유 설정을 바꾸는 요청을 **보낼 수 없게** 만들어져 있습니다. 프로그램이 해킹돼도 드라이브가 지워지지 않게 하기 위함입니다.
5. **타임머신**: 드라이브 휴지통(30일)에서 지운 파일을 되살리고, 예전 버전(30일·최대 100개)으로 되돌립니다.
6. **여러 계정**: 구글 계정을 여러 개 넣고 왼쪽 목록에서 골라 씁니다.

부가 효과: 드라이브 전체(수백 GB)가 PC에 보이지 않으므로, 개인정보 검사 프로그램 같은 전수 검사 프로그램이 느려지거나 멈추는 문제도 줄어듭니다.

## 2. 준비물

- Windows 10 또는 11 PC, 인터넷
- 구글 계정(Gmail)
- (권장) 이 PC의 Google Drive 데스크톱 앱은 끄기: 작업 표시줄 아이콘 → 설정 → 종료, 시작 시 자동 실행 해제. 켜 두면 `G:` 드라이브는 여전히 잠금 없이 열려 있습니다.

## 3. 설치

1. 홈페이지에서 [다운로드] → `DriveKeeper.zip` 받기
2. 받은 파일에서 마우스 오른쪽 → [모두 압축 풀기...] → [압축 풀기] (압축 파일 안에서 바로 실행하면 설치가 안 됨)
3. 새로 열린 창에서 `드라이브 지킴이` 폴더로 들어가 `설치하기`(Windows 명령어 스크립트) 두 번 누르기. 까만 창이 잠깐 보여도 정상
   - 프로그램이 `C:\Users\<이름>\AppData\Local\Programs\DriveKeeper` 에 복사되고, 바탕화면과 시작 메뉴에 '드라이브 지킴이' 바로가기가 생깁니다. 관리자 권한은 필요 없습니다.
   - 설치하지 않고 `app\DriveKeeper.exe` 를 바로 실행해도 됩니다.
4. "Windows의 PC 보호" 파란 창이 뜨면 → [추가 정보] → [실행] ('보안 경고' 창이면 [실행])
5. "설치가 끝났어요!" → [예] → 프로그램과 시작 도우미가 켜짐
   - 개인이 만든 프로그램이라 전자 서명이 없어 뜨는 안내입니다.
   - 백신이 막으면: 홈페이지에서 받은 파일인지 확인한 뒤 백신의 '허용'을 쓰거나, 학교·회사 PC라면 관리자에게 문의.

**업데이트**: 프로그램이 새 버전을 알려 주면(오른쪽 아래 [새 버전 받기]) 새 zip을 받아 다시 `설치하기.cmd` 를 실행합니다. 로그인·기록은 그대로 남습니다.

**지우기**: `지우기.cmd` 실행, 또는 Windows [설정] → [앱] → '드라이브 지킴이' → [제거]. 로그인 정보·작업 폴더까지 지울지 마지막에 묻습니다.

## 4. 처음 한 번: 내 구글 열쇠 만들기 (가장 중요)

드라이브 지킴이에는 개발자의 계정이나 열쇠가 **들어 있지 않습니다**. 사용자마다 **자기 구글 클라우드 프로젝트**에서 '앱 열쇠'(파일 이름 `client_secret_....json`)를 무료로 만들어 넣습니다. 그래서 내 드라이브는 오직 내 열쇠로만 열립니다.

프로그램을 처음 켜면 **시작 도우미**가 뜹니다. (다시 열기: [도움말] → [시작 도우미])

### 4-1. 열쇠 만들기 (약 5분, 모두 내 드라이브 구글 계정으로)

| 단계 | 여는 주소 | 할 일 |
|---|---|---|
| 1 프로젝트 만들기 | https://console.cloud.google.com/projectcreate | 프로젝트 이름 `drive-keeper` → [만들기]. 처음이면 나라(대한민국) 선택·약관 동의 |
| 2 드라이브 기능 켜기 | https://console.cloud.google.com/apis/library/drive.googleapis.com | 맨 위 프로젝트가 `drive-keeper` 인지 확인 → [사용] |
| 3 앱 정보 쓰기 | https://console.cloud.google.com/auth/overview | [시작하기] → 앱 이름 `드라이브 지킴이`, 지원 이메일=내 이메일 → [다음] → 대상 [외부] → [다음] → 연락처 이메일 → [다음] → 동의 체크 → [계속] → [만들기] |
| 4 나를 테스트 사용자로 | https://console.cloud.google.com/auth/audience | '테스트 사용자' [+ Add users] → 내 Gmail → [저장]. **나중에 쓸 다른 계정(학교 계정 등)도 이때 한 줄에 하나씩 같이 넣어 두면** 계정 추가가 바로 됨 |
| 5 열쇠 파일 받기 | https://console.cloud.google.com/auth/clients/create | 애플리케이션 유형 **[데스크톱 앱]** → [만들기] → 뜨는 창에서 **[JSON 다운로드]** (이 창에서만 받을 수 있음) |

- 프로그램의 열쇠 안내 창([도움말] → [내 구글 열쇠 만들기 안내])에 위 주소를 여는 파란 단추가 있습니다.
- 5번 창을 놓쳤으면: 그 클라이언트를 지우고 5번을 다시 하거나, 클라이언트를 열어 '보안 비밀 추가'.
- 콘솔 화면 글자는 바뀔 수 있습니다. 비슷한 이름의 단추를 찾으면 됩니다. 메뉴 이름: 'Google 인증 플랫폼'(예전 이름 'OAuth 동의 화면'), '대상'(Audience), '클라이언트'(Clients).

### 4-2. 열쇠 넣기

시작 도우미 2단계 [다운로드 폴더에서 찾기] → 다운로드 폴더·바탕화면에서 `client_secret*.json` 을 자동으로 찾아 넣습니다. 다른 곳에 있으면 [직접 고르기...].
- '웹 애플리케이션' 열쇠를 넣으면 거부합니다 → 5번에서 [데스크톱 앱]으로 다시 만들기.
- 열쇠는 `C:\Users\<이름>\DriveKeeper\client_secret.json` 에 저장됩니다.

### 4-3. 로그인

시작 도우미 3단계 [로그인하기] → 브라우저에서
1. 열쇠를 만든 구글 계정 고르기
2. "Google에서 확인하지 않은 앱" → 파란 [안전한 페이지로 돌아가기]가 **아니라 왼쪽 글자 [계속]**. ([계속]이 없고 [고급]이 있으면 [고급] → [...(으)로 이동(안전하지 않음)]) — 내가 만든 앱이라 나오는 안내이며 안전합니다.
3. 권한 화면: 체크 칸이 있으면 **체크** → [계속]. 체크하지 않으면 프로그램이 "구글 드라이브 권한을 받지 못했어요"라고 알려 줌 → 다시 로그인하며 체크
4. "로그인이 완료되었습니다" → 브라우저를 닫고 프로그램으로 돌아오기

**7일마다 다시 로그인**: '테스트 중' 상태 앱은 구글 규칙상 로그인이 7일마다 만료됩니다. 때가 되면 브라우저가 저절로 열리니 다시 로그인하면 됩니다. 놓쳤으면 아래 상태 표시줄의 [다시 로그인].

## 5. 화면과 기본 사용법

- **맨 위 파란 줄**: 로고·이름 / 지금 계정 이메일 / [잠금] / [보안 설정] / [도움말]
- **도구 줄**: 뒤로·앞으로·위로·새로고침 / 지금 위치(경로) / 검색 칸 / [타임머신]
- **왼쪽**: 계정별 '내 드라이브', '공유 문서함', '공유 드라이브', 맨 아래 '+ 계정 추가'
- **가운데**: 파일 목록. 열 제목을 누르면 정렬
- **아래 '편집 중인 파일'**: 이 PC로 받아 연 파일과 상태
- **맨 아래**: 상태 표시줄 (필요할 때 [다시 로그인], [업로드 다시 시작], [새 버전 받기] 단추가 나타남)

| 하고 싶은 일 | 방법 |
|---|---|
| 폴더 들어가기 | 두 번 누르기 |
| 위 폴더로 | [↑] 또는 Backspace |
| 파일 열기 | 두 번 누르기 → Word·Excel·한글 등 기본 프로그램으로 열림 |
| 고친 내용 저장 | 그 프로그램에서 Ctrl+S → 1~3초 뒤 드라이브에 반영 |
| 새 이름으로 저장 | '다른 이름으로 저장'을 처음 뜨는 폴더에 하면 원래 파일이 있던 드라이브 폴더에 새 파일로 올라감 |
| 찾기 | 검색 칸에 이름 일부 → Enter (Ctrl+F) |
| Google 문서 원본 편집 | 오른쪽 클릭 → [브라우저에서 열기] |
| PC 사본 정리 | [작업 폴더 정리] (열려 있거나 올리기 전 파일은 남김) |

단축키: Enter 열기, Backspace 위로, Alt+←/→ 뒤로/앞으로, F5 새로고침, Ctrl+F 검색, Ctrl+L 잠금.

### '편집 중인 파일' 상태 말의 뜻

| 상태 | 뜻 | 사용자가 할 일 |
|---|---|---|
| 열림 - 저장하면 자동 업로드 | 받아서 열었음 | 고치고 Ctrl+S |
| 업로드 중... | 드라이브로 보내는 중 | 기다리기 |
| 드라이브에 저장됨 14:32:10 | 그 시각에 드라이브 원본이 바뀜 | 없음 |
| 드라이브와 같음 | PC 사본과 드라이브가 같음 | 없음 |
| 업로드 실패: … - N초 후 다시 시도 | 인터넷 문제 등, 자동으로 다시 함 | 인터넷 확인. 변경 내용은 PC에 보관됨 |
| 드라이브 연결 대기 중 | 아직 연결 안 됨 | 연결되면 자동 업로드 |
| 로그인 필요 - 변경 내용은 보관 중 | 로그인 만료 | [다시 로그인] |
| 파일이 잠겨 있어 기다리는 중 | 다른 프로그램이 파일을 잡고 있음 | 잠시 기다리기 |
| 충돌 사본으로 저장됨 | 다른 곳에서 원본이 바뀌어, 덮어쓰지 않고 '이름 (충돌 사본 날짜 시간)' 새 파일로 저장 | 두 파일을 비교해 정리 |
| 업로드 보류: 파일이 손상됐거나 암호화된 것 같습니다 | 문서가 깨졌거나 랜섬웨어 의심 → 원본 보호 | 파일을 열어 확인. 정상이면 오른쪽 클릭 → [그래도 업로드] |
| 복사본 (드라이브에 반영 안 됨) | Google 문서·시트·슬라이드를 오피스 파일로 내보낸 사본 | 원본은 브라우저에서 편집 |
| 보기 전용 (드라이브에 반영 안 됨) | 편집 권한이 없는 파일 | 소유자에게 권한 요청 |
| 새 파일로 드라이브에 저장됨 | '다른 이름으로 저장'한 파일을 새로 올림 | 없음 |
| 로컬 파일이 없습니다 | PC 사본이 지워짐 | 목록에서 다시 열기 |

## 6. 비밀번호 잠금

1. [보안 설정] → 비밀번호(4자 이상) 두 번 입력
2. 잠글 때 고르기: 프로그램을 켤 때 / 컴퓨터를 N분(1~240) 동안 쓰지 않으면 / 절전 모드에서 돌아오면
3. [저장]. 이제 [잠금] 단추나 Ctrl+L로 바로 잠금
4. 모두 끄기: [보안 설정] → [모든 잠금 끄기] (비밀번호는 남아 있어 다시 켤 수 있음)

- 잠긴 동안에도 열어 둔 파일을 저장하면 드라이브에 계속 올라갑니다.
- 5번 틀리면 30초부터 최대 15분까지 기다려야 합니다(껐다 켜도 유지).
- 비밀번호를 잊으면: 잠금 화면 [비밀번호를 잊었어요] → 프로그램에 등록된 구글 계정으로 브라우저 로그인 → 새 비밀번호 정하기.
- 보안 설정 파일을 지우거나 고쳐서 잠금을 풀려 하면 같은 구글 본인 확인을 요구합니다.
- 비밀번호는 저장되지 않고 scrypt 해시만 저장됩니다.

## 7. 타임머신

- **지운 파일 되살리기**: [타임머신] → '지운 파일 되살리기' → 파일 고르기 → [선택한 항목 되살리기] → 원래 폴더로 돌아감. 최근에 고친 파일부터 보이고, 없으면 이름 일부로 [찾기]. 드라이브 휴지통 보관은 30일, 휴지통을 비우면 되살릴 수 없음.
- **예전 버전으로**: 파일 오른쪽 클릭 → [이전 버전 보기 (타임머신)] → 버전 고르기 → [이 버전 열어보기]로 확인 → [이 버전으로 되돌리기]. 지금 내용도 기록에 남음. 일반 파일 버전은 30일·최대 100개.
- Google 문서·시트·슬라이드는 브라우저의 [파일] → [버전 기록].
- 프로그램은 휴지통에서 **꺼내는 것만** 할 수 있고 지우는 것은 못 합니다.

## 8. 여러 계정

예시: 내 계정 `teacher@example.com`(열쇠를 만든 계정)에 학교 계정 `school@example.com` 을 더하기

1. 열쇠를 만든 내 계정으로 https://console.cloud.google.com/auth/audience → '테스트 사용자' [+ Add users] → `school@example.com` → [저장] (4-1의 4단계에서 같이 넣었으면 건너뜀)
2. 프로그램 왼쪽 목록 맨 아래 [+ 계정 추가] → 브라우저에서 [다른 계정 사용] → 학교 계정으로 로그인
3. "확인하지 않은 앱" → 왼쪽 [계속] → 체크 → [계속] → "로그인이 완료되었습니다" → 탭 닫기
4. 왼쪽 목록에 계정이 두 개 보임. 골라서 쓰면 되고 파일은 섞이지 않음
- 빨간 "액세스 차단됨" → 1번을 안 했거나 주소 오타. "관리자가 차단함" → 학교 관리자에게 요청하거나 개인 계정 사용
- 계정마다 로그인·작업 폴더·기록이 따로입니다.
- 빼기: 왼쪽 계정 이름 오른쪽 클릭 → [계정 제거] (드라이브 파일은 그대로, 올리지 않은 변경이 있으면 거부)

## 9. 안전 장치 (자동)

- 업로드 실패 → 자동 재시도(4초~60초 간격). 프로그램을 꺼도 다음에 켜면 이어서 올림
- 덮어쓰기 방지 → 다른 곳에서 바뀐 원본은 덮어쓰지 않고 충돌 사본으로
- 손상 방지 → 내려받기·올리기 모두 MD5 검사, 저장 도중 반쯤 쓰인 파일은 올리지 않음
- 정전 대비 → 편집 기록을 세 곳(state.json, state.bak.json, 작업 폴더마다 .gde-meta.json)에 남김
- 업로드·감시가 멈추면 5초 안에 스스로 다시 시작, Windows 종료 시 기록 저장 후 닫힘
- 랜섬웨어 대비 → 손상·암호화 의심 문서는 보류, 10분 안에 3개 이상이면 모든 업로드 정지 + [업로드 다시 시작]
- 실행 파일(.exe .bat .js .lnk 등)은 두 번 눌러도 실행하지 않음, 매크로 문서(.docm .xlsm 등)는 '인터넷 파일' 표시로 오피스가 매크로 차단
- 로그인 정보는 Windows DPAPI로 암호화(다른 PC로 복사해도 못 씀), 다른 계정으로 다시 로그인하면 거부
- 통신 허용 목록: 읽기, 파일 올리기·새 파일 만들기, 휴지통에서 꺼내기만. 삭제·휴지통 이동·휴지통 비우기·공유 변경은 통신 단계에서 차단
- 중복 실행 방지

**막을 수 없는 것**: 악성코드가 Windows 사용자 권한을 완전히 장악하면 프로그램을 거치지 않고 구글에 직접 접속할 수 있습니다. Windows 로그인 비밀번호, 자리 비울 때 Win+L, 백신·업데이트, 구글 2단계 인증을 권합니다. 의심되면 구글 계정 → 보안 → '타사 앱 및 서비스'에서 이 앱 권한 삭제 + 구글 비밀번호 변경.

## 10. 파일 위치

| 무엇 | 위치 |
|---|---|
| 프로그램 (설치했을 때) | `%LOCALAPPDATA%\Programs\DriveKeeper\DriveKeeper.exe` |
| 데이터 폴더 | `C:\Users\<이름>\DriveKeeper` |
| 앱 열쇠 | `...\DriveKeeper\client_secret.json` |
| 계정 목록 | `...\DriveKeeper\accounts.json` |
| 계정별 로그인(암호화)·기록 | `...\DriveKeeper\accounts\<계정id>\token.json`, `state.json`, `state.bak.json` |
| 작업 폴더(받은 파일) | `...\DriveKeeper\accounts\<계정id>\work\` (예전 버전에서 옮겨 온 첫 계정은 `...\DriveKeeper\work\`) |
| 보안 설정(암호화) | `...\DriveKeeper\security.json` |
| 기록(문제 확인용) | `...\DriveKeeper\app.log` ([도움말] → [기록 파일 위치 열기]) |

예전 이름(GDriveExplorer) 시절 데이터는 처음 실행 때 자동으로 옮겨집니다.

## 11. 문제 해결 (증상 → 해결)

| 증상 | 원인 | 해결 |
|---|---|---|
| "앱 열쇠(client_secret.json)가 아직 없어요" | 열쇠를 안 넣음 | [도움말] → [시작 도우미] → 4장 |
| 로그인 때 "액세스 차단됨" / "access_denied" | 그 계정이 테스트 사용자가 아님, 또는 주소 오타 | 4-1의 4번 다시 |
| "redirect_uri_mismatch" | 웹 애플리케이션 열쇠를 넣음 | 데스크톱 앱 열쇠로 다시 만들어 넣기 |
| "열쇠 파일을 찾지 못했어요" | [JSON 다운로드]를 안 누름, 또는 다른 폴더에 저장 | 4-1의 5번 다시, 또는 [직접 고르기...] |
| "구글 드라이브 권한을 받지 못했어요" | 권한 화면에서 체크하지 않고 [계속] | 다시 로그인하며 체크 칸 체크 |
| "관리자가 차단함" | 학교·회사 구글 계정 정책 | 관리자에게 허용 요청 또는 개인 계정 |
| 로그인 시간 초과 | 5분 안에 로그인 안 함 | 다시 시도 |
| 7일마다 브라우저가 열림 | 테스트 중 앱의 구글 규칙 | 정상. 다시 로그인 |
| 파일이 안 열림 | 그 형식을 여는 프로그램이 없음 | 해당 프로그램 설치, 또는 [파일 위치]에서 직접 |
| 저장했는데 안 올라감 | 상태 칸 확인 (5장 표) | 상태에 맞게 |
| "업로드 보류" | 파일 손상·암호화 의심 | 파일 확인 후 [그래도 업로드], 여러 개면 백신 검사 |
| 충돌 사본이 생김 | 다른 PC에서 같은 파일을 고침 | 두 파일 비교 후 정리 |
| 검색해도 안 나옴 | 구글 검색은 이름 앞부분 기준 | 다른 단어로, 또는 폴더에서 찾기 |
| "Windows의 PC 보호" | 서명 없는 프로그램 | [추가 정보] → [실행] |
| 백신이 막음 | 개인 제작 프로그램 오탐 | 출처 확인 후 허용 또는 관리자 문의 |
| 비밀번호를 잊음 | — | 잠금 화면 [비밀번호를 잊었어요] |
| 이미 실행 중이라고 함 | 한 번에 하나만 실행 | 작업 표시줄의 창 사용 |

문제가 계속되면 `app.log`(비밀번호·로그인 코드는 기록되지 않음)를 개발자에게 보내 주세요.
