드라이브 지킴이

개인정보처리방침

시행일: 2026년 10월 24일

드라이브 지킴이(이하 “프로그램”)는 사용자의 개인정보를 수집하지 않습니다. 이 문서는 프로그램이 어떤 정보를 어디에서 다루는지 알려 드립니다.

1. 개발자가 받는 정보

없습니다. 프로그램에는 개발자의 서버가 없으며, 사용자의 파일·계정·사용 기록을 개발자에게 보내지 않습니다.

2. 프로그램이 다루는 정보와 위치

  • 구글 드라이브 파일: 사용자가 연 파일만 사용자의 PC(작업 폴더)로 내려받고, 저장하면 사용자의 구글 드라이브로 올립니다. 구글의 공식 API와 사용자가 직접 만든 앱 열쇠를 씁니다.
  • 로그인 정보(토큰): 사용자의 PC에만 저장하며, Windows 사용자 계정으로 암호화합니다.
  • 비밀번호 잠금: 비밀번호 자체는 저장하지 않고, 되돌릴 수 없는 해시 값만 사용자의 PC에 암호화해 저장합니다.
  • 기록 파일(app.log): 문제 확인용으로 사용자의 PC에만 남깁니다. 비밀번호와 로그인 코드는 기록하지 않습니다.

3. 외부로 나가는 연결

  • Google (드라이브 목록·내려받기·올리기, 로그인): 사용자의 구글 계정과 사용자가 만든 열쇠로만 연결합니다.
  • GitHub (새 버전 확인): 공개된 최신 버전 번호만 읽습니다. 사용자 정보는 보내지 않습니다.

4. 구글 사용자 데이터의 사용

프로그램은 구글 드라이브 데이터를 사용자가 요청한 파일 열기·저장·되살리기에만 사용하며, 다른 곳으로 보내거나 광고·분석에 쓰지 않습니다. 프로그램은 드라이브의 파일을 삭제하거나 공유 설정을 바꾸는 요청을 보내지 않도록 만들어져 있습니다.

5. 정보 지우기

프로그램을 제거할 때 로그인 정보와 작업 폴더를 함께 지울 수 있습니다. 구글 계정 → 보안 → ‘타사 앱 및 서비스’에서 이 앱의 접근 권한을 언제든 삭제할 수 있습니다.
