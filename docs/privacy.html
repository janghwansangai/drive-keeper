드라이브 지킴이

개인정보처리방침

시행일: 2026년 10월 31일 · 만든 사람: 다있쌤 로디

드라이브 지킴이(이하 “프로그램”)는 사용자의 개인정보를 저절로 수집하지 않습니다. 사용자가 오류 신고를 직접 보낼 때만, 적어 보낸 내용이 만든 사람에게 전달됩니다. 이 문서는 프로그램이 어떤 정보를 어디에서 다루는지 알려 드립니다.

1. 만든 사람이 받는 정보

프로그램이 저절로 보내는 정보는 없습니다. 사용자의 파일·계정·사용 기록은 만든 사람에게 보내지 않습니다.

사용자가 프로그램의 [도움말] → [오류 신고 · 개선 의견 보내기]나 홈페이지의 오류 신고 단추로 직접 보낼 때만 다음이 전달됩니다.

  • 사용자가 적은 내용: 신고 종류, 제목, 내용, (적었다면) 연락처
  • 프로그램 버전과 신고한 화면 이름 (예: “메인 화면 · 내 드라이브”). 파일·폴더·계정 이름은 넣지 않습니다.
  • 신고 창의 ‘화면 정보와 최근 오류 기록 함께 보내기’를 켜 두었다면: 신고 창 주소, 브라우저 종류·언어·시간대, 화면 크기, 그 창에서 난 최근 오류 기록. 이 칸은 끌 수 있습니다.

이 내용은 만든 사람의 오류 취합 센터(Google Apps Script)에 모이고, 오류를 고치고 답하는 데만 씁니다. 답이 필요 없으면 연락처는 비워 두세요.

2. 프로그램이 다루는 정보와 위치

  • 구글 드라이브 파일: 사용자가 연 파일만 사용자의 PC(작업 폴더)로 내려받고, 저장하면 사용자의 구글 드라이브로 올립니다. 구글의 공식 API와 사용자가 직접 만든 앱 열쇠를 씁니다.
  • 로그인 정보(토큰): 사용자의 PC에만 저장하며, Windows 사용자 계정으로 암호화합니다.
  • 비밀번호 잠금: 비밀번호 자체는 저장하지 않고, 되돌릴 수 없는 해시 값만 사용자의 PC에 암호화해 저장합니다.
  • 기록 파일(app.log): 문제 확인용으로 사용자의 PC에만 남깁니다. 비밀번호와 로그인 코드는 기록하지 않습니다.

3. 외부로 나가는 연결

  • Google (드라이브 목록·내려받기·올리기, 로그인): 사용자의 구글 계정과 사용자가 만든 열쇠로만 연결합니다.
  • GitHub (새 버전 확인·업데이트): 공개된 최신 버전 번호를 읽고, [지금 업데이트]를 누르면 새 버전 파일을 받습니다. 사용자 정보는 보내지 않습니다.
  • 오류 취합 센터 (script.google.com): 사용자가 오류 신고를 보낼 때만 연결합니다. 홈페이지는 오류 신고 단추를 보여 주려고 이 주소에서 작은 스크립트를 불러옵니다.

4. 구글 사용자 데이터의 사용

프로그램은 구글 드라이브 데이터를 사용자가 요청한 파일 열기·저장·되살리기에만 사용하며, 다른 곳으로 보내거나 광고·분석에 쓰지 않습니다. 프로그램은 드라이브의 파일을 삭제하거나 공유 설정을 바꾸는 요청을 보내지 않도록 만들어져 있습니다.

5. 정보 지우기

프로그램을 제거할 때 로그인 정보와 작업 폴더를 함께 지울 수 있습니다. 구글 계정 → 보안 → ‘타사 앱 및 서비스’에서 이 앱의 접근 권한을 언제든 삭제할 수 있습니다.

6. 문의

프로그램의 [도움말] → [오류 신고 · 개선 의견 보내기], 이 페이지 오른쪽 아래 오류 신고 단추, 또는 GitHub 이슈로 문의해 주세요.
