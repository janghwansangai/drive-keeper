왜 필요할까요

드라이브를 연결하는 순간, 문이 활짝 열려요

구글 드라이브 데스크톱으로 G: 드라이브를 만들면 편리하지만, 잠금 장치가 없어요. 드라이브 지킴이는 편리함은 그대로 두고 빈틈만 막았어요.

😟 드라이브를 그냥 연결하면

  • ✕컴퓨터를 쓰는 누구나 비밀번호 없이 모든 파일을 열 수 있어요
  • ✕실수나 악성코드로 한꺼번에 지워질 수 있어요
  • ✕수백 GB가 통째로 보여서 검사 프로그램이 느려지거나 멈춰요

😊 드라이브 지킴이를 쓰면

  • ✓비밀번호를 넣어야 열리고, 자리를 비우면 저절로 잠겨요
  • ✓이 프로그램으로는 파일을 지우거나 공유를 바꿀 수 없어요
  • ✓필요한 파일 하나만 꺼내 쓰고, 저장하면 저절로 올라가요
기능

지키는 것도, 쓰는 것도 쉽게

어려운 설정 없이 켜기만 하면 지켜 줘요.

비밀번호 잠금

켤 때, 컴퓨터를 몇 분 안 쓸 때, 절전에서 깼을 때 저절로 잠겨요. 단추 하나로 바로 잠글 수도 있어요.

지우기 차단

프로그램이 해킹돼도 드라이브를 지우거나, 휴지통에 넣거나, 공유를 바꾸는 요청을 보낼 수 없어요.

저장하면 자동 업로드

한글·Word·Excel에서 Ctrl+S만 누르면 1~3초 안에 드라이브의 원본이 바뀌어요.

타임머신

실수로 지운 파일을 되살리고, 잘못 저장한 파일을 예전 내용으로 되돌려요.

여러 계정

개인 계정과 학교·회사 계정을 함께 넣고 왼쪽 목록에서 골라 써요. 파일이 섞이지 않아요.

랜섬웨어·정전 대비

파일이 이상하게 바뀌면 올리지 않고 원본을 지켜요. 정전이 나도 올리지 못한 변경을 기억해 뒀다가 다시 올려요.

둘러보기

이렇게 생겼어요

처음엔 시작 도우미가 안내해요

세 단계만 따라 하면 돼요.

  1. 내 구글 열쇠 만들기 ([그림으로 따라 하기]를 누르면 한 단계씩)
  2. 받은 열쇠 파일을 자동으로 찾아 넣기
  3. 내 구글 계정으로 로그인

자리를 비우면 저절로 잠겨요

비밀번호를 넣어야 다시 열려요. 잠겨 있는 동안에도 열어 둔 파일의 저장 내용은 계속 드라이브에 올라가요. 비밀번호를 잊으면 내 구글 계정으로 본인 확인을 하고 새로 정할 수 있어요.

지운 파일도 되살려요

구글 드라이브의 휴지통(30일)과 버전 기록(30일·최대 100개)을 이용해, 지운 파일을 원래 폴더로 되돌리고 예전 내용으로 되돌려요.

잠글 때를 내가 골라요

프로그램을 켤 때, 컴퓨터를 몇 분 안 쓸 때, 절전에서 돌아올 때. 필요 없으면 ‘모든 잠금 끄기’ 한 번이면 돼요.

자주 묻는 질문

궁금한 것들

정말 무료인가요? 제 정보를 가져가지 않나요?

네, 무료예요. 개발자에게 아무 정보도 가지 않아요. 서버가 없고, 파일은 내 컴퓨터와 내 구글 드라이브 사이에서만 오가요. 업데이트 확인 때 최신 버전 번호만 GitHub에서 읽어요.

‘구글 열쇠’는 왜 직접 만들어야 하나요?

다른 사람의 열쇠를 함께 나눠 쓰지 않고, 내 드라이브는 오직 내 열쇠로만 열리게 하려고요. 구글 클라우드에서 무료로 5분이면 만들 수 있어요. 그림으로 따라 하기를 보며 단추만 차례로 누르면 돼요.

로그인할 때 ‘확인하지 않은 앱’이라고 나와요.

내가 만든 열쇠라서 나오는 안내예요. 파란 단추 말고 왼쪽 글자 [계속]을 누르면 돼요([계속]이 없으면 [고급] → [...(으)로 이동]). 같은 이유로 구글 규칙상 7일에 한 번 다시 로그인해요(브라우저가 저절로 열려요).

‘Windows의 PC 보호’ 파란 창이 떠요.

개인이 만든 프로그램이라 전자 서명이 없어서 나오는 안내예요. [추가 정보] → [실행]을 누르면 돼요. 이 홈페이지에서 받은 파일인지 꼭 확인하세요.

Google 드라이브 데스크톱과 함께 써도 되나요?

같이 켜 두면 G: 드라이브가 여전히 비밀번호 없이 열려요. 잠금 효과를 보려면 Google 드라이브 데스크톱은 종료하고 자동 실행을 꺼 주세요.

한글(HWP) 파일도 되나요?

네. 한글·Word·Excel·PowerPoint 등 컴퓨터에 깔린 프로그램으로 열고, 저장하면 드라이브에 올라가요. Google 문서·시트는 오피스 파일 복사본으로 열리고, 원본은 브라우저에서 고쳐요.

여러 컴퓨터에서 같은 파일을 고치면요?

다른 곳에서 바뀐 원본을 덮어쓰지 않고, 내 변경은 ‘(충돌 사본 날짜 시간)’이라는 새 파일로 올려요. 아무것도 잃어버리지 않아요.

구글 계정을 하나 더 넣을 수 있나요?

네. 열쇠를 만든 구글 화면의 ‘테스트 사용자’에 그 계정 주소를 넣고, 프로그램 왼쪽 맨 아래 [+ 계정 추가]를 누르면 돼요. 학교 계정을 추가하는 예시를 그림으로 볼 수 있어요.

새 버전은 어떻게 받나요?

새 버전이 나오면 프로그램 오른쪽 아래에 [새 버전 받기]가 생겨요. 받은 파일로 ‘설치하기’를 다시 하면 되고, 로그인과 기록은 그대로 남아요.
